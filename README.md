# 薄荷铃 · Mint Bell

银发、薄荷色裙摆、小猫挎包、花边白短袜和黑色珍妮皮鞋。由全身三视图转为像素风桌面伙伴。

![薄荷铃的九种动作](preview/animations.gif)

## 在桌面端导入

复制下面整行链接，并交给系统打开（Windows 可粘贴到「运行」，按 **Win + R** 打开）。如果桌面端已启用智能伙伴，链接会打开安装页面。

```text
codex://pets/install?name=%E8%96%84%E8%8D%B7%E9%93%83&imageUrl=https%3A%2F%2Fraw.githubusercontent.com%2Fmotionalpha84%2FCodex-Desktop-pet-Firefly%2Fmain%2Fspritesheet.png&description=%E9%93%B6%E5%8F%91%E3%80%81%E8%96%84%E8%8D%B7%E8%89%B2%E8%A3%99%E6%91%86%EF%BC%8C%E9%9A%8F%E8%BA%AB%E5%B8%A6%E7%9D%80%E5%B0%8F%E7%8C%AB%E7%8E%A9%E5%81%B6%E7%9A%84%E5%83%8F%E7%B4%A0%E4%BC%99%E4%BC%B4%E3%80%82&spriteVersionNumber=2
```

也可以[下载透明精灵图](https://raw.githubusercontent.com/motionalpha84/Codex-Desktop-pet-Firefly/main/spritesheet.png)，在支持 v2 精灵图的客户端导入。参见 [OpenAI 桌面端安装链接说明](https://learn.chatgpt.com/docs/app/commands#pets)。
